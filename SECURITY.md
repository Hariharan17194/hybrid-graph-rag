# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository, or email hariharan.padmanabhan17@gmail.com.

You can expect an acknowledgement within 72 hours.

## Secrets

This project reads API keys from `.env` (never committed — see `.env.example`).
If you believe a key was committed, report it privately so it can be rotated.
